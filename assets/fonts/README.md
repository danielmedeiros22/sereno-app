# Fontes para exportação

Noto Sans Regular/Bold e Noto Emoji são distribuídas com o aplicativo para gerar relatórios sem buscar fontes de terceiros durante a exportação. Licenças SIL Open Font License incluídas nesta pasta.

Fontes oficiais:
- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- https://github.com/google/fonts/tree/main/ofl/notoemoji

Os bytes ficam versionados no repositório. O estilo dos emojis no PDF é monocromático; não é necessário enviar dados do usuário para renderizá-los.
